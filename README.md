Работа с китайским RFID считывателем на питоне от чата гпт.

На плате считывателя написано pmx-v624-c

Это USB HID устройство. VID=0x2518, PID=0x6018

В норме работает через свое приложение nfcPro_x64.exe

В программе считыватель распознается как wCopy NSR109-HIDICV806N

Приложение скачивается отсюда: https://www.xixei.com/nfc/tool/soft/down_enus.html

Нужно добавить после покупки считывателей аналогичные устройства семейства, например WBW106-IDIC, у них будет другой  VID / PID
